# Project-MihateOS
leaning how to develop OS, Moreover make new OS name MihateOS

---

architechture x86 cossover on Mackbook pro M1 13"

install 
```
brew install qemu
brew install x86_64-elf-gcc
brew install x86_64-elf-binutils
brew install i686-elf-grub
brew install xorriso
brew install mtools
brew install nasm
```
or
```
brew install qemu x86_64-elf-gcc x86_64-elf-binutils i686-elf-grub xorriso mtools nasm
```
Build
```
make
```
Clear
```
make clean
```
Run QEMU
```
make run
```
